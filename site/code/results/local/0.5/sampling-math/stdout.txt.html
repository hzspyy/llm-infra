    D 从未出现，三种惩罚都不动它——惩罚只改已出现 token 的分数，不改其余部分。
    repetition 看 prompt ∪ 已生成，frequency 按出现次数线性扣，presence 只看出现与否。
    B 只在 prompt 里：repetition 罚到它，frequency/presence 不罚（frequency=0.5 那行 B 仍是 +0.5000）。

    随机采样：judgement 是分布检验，不是逐次相等。自由度 2，α=0.05 的临界值 5.991。
    3 个 seed 里有 1 个超过临界值。这本身就是检验的含义：α=0.05 表示正确的实现也有 5% 的单次运行会被判为不通过，
    跑 3 个 seed 至少出现一次的概率是 1-0.95³≈14%。判断实现是否正确要看多次重复的整体表现，不能凭一次 χ² 下结论。
    统计涨落的量级是 1/√N = 0.00224，实测 max|Δ| 与之同量级——要求「同 seed 同 token」在跨引擎场景下没有意义。

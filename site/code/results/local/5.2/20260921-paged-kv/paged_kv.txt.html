L5.2-A 分页 KV 状态机：fork / COW / 驱逐 与无缓存参照逐位置对拍
值函数 v_p = f(v_(p-1), t_p) mod 2^61-1，与 token 前缀一一对应

[A] 单请求 + 重复请求：复用块的内容是否等于重算
  r0: tokens=2048 computed=2048 blocks=128
     idx  block  ref  valid  full  cached
       0      0    1     16  True    True
       1      1    1     16  True    True
       2      2    1     16  True    True
    ...（共 128 块，其余省略）
    r0 首次：复用 0 块 / 重算 2048 token；内容对拍 2048 位置，不一致 0
    r1 复用：复用 127 块 / 重算 16 token；内容对拍 2048 位置，不一致 0
    r2 关闭 num_tokens-1 上限（块池原始语义）：复用 128 块 / 重算 0 token；内容不一致 0

[B] 共享前缀：非对齐边界 + 中段改变 + 相同后缀不同前缀
        共享前缀     复用块   重算token     对拍位置    不一致   公式⌊p/16⌋
           0       0       256      256      0          0
          15       0       256      256      0          0
          16       1       240      256      0          1
          17       1       240      256      0          1
         127       7       144      256      0          7
         128       8       128      256      0          8
         129       8       128      256      0          8
    中段第 96 个 token 改为不同值：复用块 6（只到断点前一块 = 6），重算 160 token，内容不一致 0

[C] fork 后分叉写入：COW 是否保护父序列
    块对齐：COW 复制 0 次；父序列内容不一致 0，子序列不一致 0（对拍 68/68 位置）
      父表尾：[(3, 2, 16), (4, 1, 4)]  子表尾：[(3, 2, 16), (5, 1, 4)]
    块内偏移：COW 复制 1 次；父序列内容不一致 0，子序列不一致 0（对拍 74/74 位置）
      父表尾：[(3, 2, 16), (4, 1, 10)]  子表尾：[(3, 2, 16), (5, 1, 10)]
    关闭 COW：别名写入 2 次；后写的父序列内容不一致 1 位置（首个位置 70），先写的子序列不一致 0 位置

[D] 驱逐顺序与缓存压力：空闲链 LRU 是否先打尾部块
    6 块池、6 块序列：淘汰 [5, 4] 后仍可匹配 4 块（保留前 4 块前缀，被淘汰的是尾部）
    池 32 块（热前缀 8 块 + 3 条冷请求各 2 块，跑 4 轮）：逐轮命中块 [0, 14, 14, 14]，内容不一致 0，分配 14，归还 56
    池 16 块（热前缀 8 块 + 3 条冷请求各 2 块，跑 4 轮）：逐轮命中块 [0, 14, 14, 14]，内容不一致 0，分配 14，归还 56
    池 12 块（热前缀 8 块 + 3 条冷请求各 2 块，跑 4 轮）：逐轮命中块 [0, 6, 6, 6]，内容不一致 0，分配 38，归还 56
    池 10 块（热前缀 8 块 + 3 条冷请求各 2 块，跑 4 轮）：逐轮命中块 [0, 4, 4, 4]，内容不一致 0，分配 44，归还 56

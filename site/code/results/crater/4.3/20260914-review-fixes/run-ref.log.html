==============================================================================
[A] 层输出重建目标与三种量化方法
==============================================================================
  X (256, 128)（校准样本 256，每 16 个通道一个 ×10 离群通道）
  W (64, 128)  group_size=32  全部 FP64
  通道幅度：普通通道均值 0.810，离群通道均值 7.942

--- A1 目标函数：为什么不是最小化权重误差 --------------------------------------------------
  RTN：权重误差 9.7172e-02  输出误差 1.0018e-01
  H = XᵀX 的形状 (128, 128)，特征值范围 [2.585e+01, 3.339e+04]（对称半正定）
  层输出误差平方 = tr((Ŵ − W) H (Ŵ − W)ᵀ)，H=XᵀX，包含跨组项。
  scale 分组不等于 Hessian 块对角近似；权重误差忽略了 X。

--- A2 clipping：在裁剪比例上按校准数据搜索 ---------------------------------------------
  RTN（无裁剪）      权重误差 9.7172e-02  输出误差 1.0018e-01
  最优裁剪比例 0.98   权重误差 9.5935e-02  输出误差 9.8842e-02
  两个指标的关系：权重误差 9.7172e-02 → 9.5935e-02，输出误差 1.0018e-01 → 9.8842e-02
  裁剪比例的搜索目标是输出误差；权重误差只是副产物，两者不同步。

--- A3 GPTQ：用 Hinv 逐列补偿 ---------------------------------------------------
  GPTQ               权重误差 1.7034e-01  输出误差 8.5625e-02
  完整 H 的 U[0,0] = 0.007939；UᵀU 与 H⁻¹ 的最大差 1.73e-18
  两列中间状态：Hinv[0,1]/Hinv[0,0] = -0.450000，补偿量与闭式解的最大相对差 2.51e-16
  这条同时说明为什么 ρ=0 时补偿为零：与第 0 列不相关的列没有可传递的误差。

--- A4 AWQ：通道等价缩放 ---------------------------------------------------------
  AWQ（看激活）      最优 p=0.30  权重误差 1.1450e-01  输出误差 6.4819e-02
  AWQ（只看权重均值） 权重误差 9.8390e-02  输出误差 9.8552e-02
  激活统计比权重统计更贴近目标：AWQ 的缩放是围绕 X 设计的。

--- A5 校准分布改变后的误差 ---------------------------------------------------------
  偏移-普通高斯  RTN 9.6464e-02  clip 9.6214e-02  GPTQ 1.7304e-01  AWQ 1.1410e-01
  同分布-独立离群样本 RTN 9.8874e-02  clip 9.7829e-02  GPTQ 1.1358e-01  AWQ 6.3526e-02
  偏移-独立相关样本 RTN 9.8060e-02  clip 9.7321e-02  GPTQ 1.6661e-01  AWQ 1.1485e-01
  校准集只影响三种方法的**参数**（scale / 补偿 / 缩放），
  评测集换分布后误差排序会变，这就是校准/评测必须分开的原因。

--- B1 E2M1 与 E8M0 的参照表 ---------------------------------------------------
  E2M1 可表示幅度（3 位指数+尾数）: [0.0, 0.5, 1.0, 1.5, 2.0, 3.0, 4.0, 6.0]
  16 个码的取值: [0.0, 0.5, 1.0, 1.5, 2.0, 3.0, 4.0, 6.0, -0.0, -0.5, -1.0, -1.5, -2.0, -3.0, -4.0, -6.0]
  已知值 [0.0, 0.5, -1.5, 6.0, -6.0] -> 码 [0, 1, 11, 7, 15] -> 还原 [0.0, 0.5, -1.5, 6.0, -6.0]  精确往返 True
    0.3 -> 码 1 -> 0.50（四舍五入到最近的可表示值）
    0.8 -> 码 2 -> 1.00（四舍五入到最近的可表示值）
    2.6 -> 码 5 -> 3.00（四舍五入到最近的可表示值）
    5.2 -> 码 7 -> 6.00（四舍五入到最近的可表示值）
  E8M0：两个 block 的 scale [2.0, 2.0]（指数码 [128, 128]，bias=127）

  用例                                      首个不同块      共有前缀块                          结论
  LoRA 名字 A（其余不变）                             0          0                 进键：第 0 块即不同
  LoRA 名字 A vs B                              0          0                  进键：名字不同即不同
  同名 A、不同路径/权重                                —          6                   不进键：同名即同键
  cache_salt = tenant-1                       0          0  进键：salt 只加在第 0 块，尾 5 块相同 0
  temperature/top_p/seed 改变                   —          6                         不进键
  同一块 token、不同父块哈希                            0          0                     进键：滚动哈希

PyTorch autograd 引擎：反向图、调度与保存值

从梯度公式深入到 Node/Edge、GraphTask、就绪队列和 AccumulateGrad，解释保存值、版本检查、流语义与反向内存；以有分支的 mini 引擎对拍。

实测机器 本地 CPU mini；crater GPU 流与内存实验待后续前置 0.0b（最小反向传播）· 2.0b（算子分发）

本章回答三个问题

0.0b 手工推导了一个两层 MLP 的反向传播公式，但没讲 PyTorch 如何自动构建和执行反向图。本章从 loss.backward() 进入 autograd 引擎，解释反向图的构建、调度、梯度累积和保存值释放。

  1. loss.backward() 如何构造和执行一次 GraphTask？
  2. 共享节点的梯度何时汇合，保存值何时释放？
  3. 梯度模式、原地修改和异步流怎样影响正确性？

心智模型：反向图的构建与执行

关键要点： - 前向构建，反向执行 - 拓扑序保证依赖正确 - 共享节点的梯度累积 - 保存值尽早释放

第一步：前向如何构建反向图

grad_fn 的创建

每个需要梯度的算子执行时，会创建一个反向节点（grad_fn）：

# labs/L7/trace_grad_fn.py
import torch

print("=== 追踪 grad_fn 的创建 ===")
print()

x = torch.randn(2, 3, requires_grad=True)
print(f"x.grad_fn: {x.grad_fn}")  # None（叶子节点）
print(f"x.requires_grad: {x.requires_grad}")
print()

# 第一个算子：矩阵乘
W = torch.randn(4, 3, requires_grad=True)
h = x @ W.t()
print(f"h = x @ W.t()")
print(f"h.grad_fn: {h.grad_fn}")
print(f"h.grad_fn.next_functions: {h.grad_fn.next_functions}")
print()

# 第二个算子：ReLU
y = torch.relu(h)
print(f"y = relu(h)")
print(f"y.grad_fn: {y.grad_fn}")
print(f"y.grad_fn.next_functions: {y.grad_fn.next_functions}")
print()

# 第三个算子：求和
loss = y.sum()
print(f"loss = y.sum()")
print(f"loss.grad_fn: {loss.grad_fn}")
print(f"loss.grad_fn.next_functions: {loss.grad_fn.next_functions}")

运行输出：

=== 追踪 grad_fn 的创建 ===

x.grad_fn: None
x.requires_grad: True

h = x @ W.t()
h.grad_fn: <MmBackward0 object at 0x...>
h.grad_fn.next_functions: ((<AccumulateGrad object at 0x...>, 0), (<TBackward0 object at 0x...>, 0))

y = relu(h)
y.grad_fn: <ReluBackward0 object at 0x...>
y.grad_fn.next_functions: ((<MmBackward0 object at 0x...>, 0),)

loss.grad_fn: <SumBackward0 object at 0x...>
loss.grad_fn.next_functions: ((<ReluBackward0 object at 0x...>, 0),)

从输出可以看出： - 叶子节点（x）没有 grad_fn - 每个算子创建一个 grad_fn（MmBackward0、ReluBackward0、SumBackward0） - next_functions 指向前一个节点（反向图的边）

反向图的结构

# labs/L7/visualize_grad_graph.py
import torch

def print_grad_graph(tensor, depth=0):
    """递归打印反向图"""
    indent = "  " * depth
    if tensor.grad_fn is None:
        print(f"{indent}[Leaf] {tensor.shape}")
        return

    print(f"{indent}{tensor.grad_fn.__class__.__name__}")
    for next_fn, _ in tensor.grad_fn.next_functions:
        if next_fn is not None:
            print(f"{indent}  ↓")
            if hasattr(next_fn, 'variable'):
                # AccumulateGrad
                print(f"{indent}  [AccumulateGrad] {next_fn.variable.shape}")
            else:
                # 递归打印
                # 注意：这里简化了，实际需要保存访问过的节点避免环
                print(f"{indent}  {next_fn.__class__.__name__}")

# 示例
x = torch.randn(2, 3, requires_grad=True)
W = torch.randn(4, 3, requires_grad=True)
h = x @ W.t()
y = torch.relu(h)
loss = y.sum()

print("=== 反向图结构 ===")
print_grad_graph(loss)

典型输出：

=== 反向图结构 ===
SumBackward0
  ↓
  ReluBackward0
  ↓
  MmBackward0
  ↓
  [AccumulateGrad] torch.Size([2, 3])
  ↓
  TBackward0
  ↓
  [AccumulateGrad] torch.Size([4, 3])

关键要点： - 反向图是 DAG（有向无环图） - 边的方向：从 loss 指向叶子节点 - AccumulateGrad 是终点（把梯度写入 tensor.grad）

第二步：backward() 如何执行反向图

GraphTask 的创建

loss.backward() 做了什么：

# labs/L7/trace_backward.py
import torch

x = torch.randn(2, 3, requires_grad=True)
W = torch.randn(4, 3, requires_grad=True)
h = x @ W.t()
y = torch.relu(h)
loss = y.sum()

print("=== 执行 backward ===")
print(f"执行前 x.grad: {x.grad}")
print(f"执行前 W.grad: {W.grad}")
print()

# 执行反向传播
loss.backward()

print("执行后 x.grad:")
print(x.grad)
print()
print("执行后 W.grad:")
print(W.grad)

backward() 内部流程（简化）：

  1. 创建 GraphTask
  2. 将 loss.grad_fn 入队（初始梯度为 1）
  3. 循环执行就绪队列中的节点
  4. 每个节点执行完后，更新后继的依赖计数
  5. 依赖计数变 0 的节点入队
  6. 直到所有 AccumulateGrad 执行完

拓扑排序的必要性

下面用一个共享节点的例子说明执行顺序：

# labs/L7/why_topological_order.py
import torch

# 场景：共享参数
x = torch.randn(2, 3, requires_grad=True)
W = torch.randn(3, 3, requires_grad=True)

# 使用 W 两次
h1 = x @ W      # 第一次使用
h2 = h1 @ W     # 第二次使用
loss = h2.sum()

print("=== 共享参数的反向图 ===")
print(f"W 被使用了 2 次")
print()

loss.backward()

print(f"W.grad 的形状: {W.grad.shape}")
print(f"W.grad 包含两次使用的梯度贡献")
print()
print("如果不按拓扑序执行，会导致：")
print("  - 梯度计算错误（后继还没计算完就累加）")
print("  - 保存值过早释放（还有节点需要使用）")

关键原则：

拓扑序保证：一个节点执行时，其所有后继已经计算完成。

第三步：梯度累积与共享节点

梯度累积的机制

当同一个参数被多次使用时，梯度需要累加：

# labs/L7/gradient_accumulation.py
import torch

print("=== 梯度累积演示 ===")
print()

# 场景 1：参数被使用一次
W1 = torch.tensor([[1.0, 2.0]], requires_grad=True)
x = torch.tensor([[1.0], [1.0]])
y1 = W1 @ x
loss1 = y1.sum()
loss1.backward()
print(f"场景 1: W 被使用 1 次")
print(f"W1.grad: {W1.grad}")
print()

# 场景 2：参数被使用两次
W2 = torch.tensor([[1.0, 2.0]], requires_grad=True)
y2 = W2 @ x      # 第一次
y3 = W2 @ x      # 第二次（相同的计算）
loss2 = (y2 + y3).sum()
loss2.backward()
print(f"场景 2: W 被使用 2 次")
print(f"W2.grad: {W2.grad}")
print(f"梯度是场景 1 的 2 倍（因为用了 2 次）")
print()

# 场景 3：手动多次 backward（不清空 grad）
W3 = torch.tensor([[1.0, 2.0]], requires_grad=True)
for i in range(3):
    y = W3 @ x
    loss = y.sum()
    loss.backward()  # 不清空 grad
    print(f"第 {i+1} 次 backward 后 W3.grad: {W3.grad}")

运行输出：

=== 梯度累积演示 ===

场景 1: W 被使用 1 次
W1.grad: tensor([[1., 1.]])

场景 2: W 被使用 2 次
W2.grad: tensor([[2., 2.]])
梯度是场景 1 的 2 倍（因为用了 2 次）

第 1 次 backward 后 W3.grad: tensor([[1., 1.]])
第 2 次 backward 后 W3.grad: tensor([[2., 2.]])
第 3 次 backward 后 W3.grad: tensor([[3., 3.]])

关键要点： - PyTorch 默认累积梯度（不自动清零） - 训练循环需要手动 optimizer.zero_grad() 或 tensor.grad.zero_()

AccumulateGrad 的作用

AccumulateGrad 是反向图的终点，负责把梯度写入 tensor.grad：

# labs/L7/accumulate_grad_demo.py
import torch

x = torch.randn(2, 3, requires_grad=True)
y = x * 2
loss = y.sum()

print("=== AccumulateGrad 的作用 ===")
print(f"x.grad 初始: {x.grad}")
print()

# 第一次 backward
loss.backward()
print(f"第一次 backward 后 x.grad:")
print(x.grad)
print()

# 不清零，再次 backward
y2 = x * 3
loss2 = y2.sum()
loss2.backward()
print(f"第二次 backward 后 x.grad（累积）:")
print(x.grad)
print()

# 清零后 backward
x.grad.zero_()
y3 = x * 4
loss3 = y3.sum()
loss3.backward()
print(f"清零后 backward:")
print(x.grad)

第四步：保存值与内存管理

什么是保存值

反向传播需要用到前向的中间结果：

# labs/L7/saved_tensors.py
import torch

x = torch.randn(2, 3, requires_grad=True)
W = torch.randn(4, 3, requires_grad=True)
h = x @ W.t()

print("=== 保存值 ===")
print(f"h.grad_fn: {h.grad_fn}")
print()

# 反向传播的 matmul 需要保存 x 和 W
# 因为: ∂loss/∂W = ∂loss/∂h @ x.t()
#      ∂loss/∂x = ∂loss/∂h @ W

# 查看保存的张量
saved = h.grad_fn.saved_tensors
print(f"保存的张量数量: {len(saved)}")
for i, t in enumerate(saved):
    print(f"  saved[{i}]: {t.shape}")

保存值的时机： - 前向执行时保存 - 反向执行后释放

内存优化：checkpointing

对于深度网络，保存所有中间值会占用大量内存。PyTorch 提供 checkpoint 机制：

# labs/L7/checkpoint_demo.py
import torch
from torch.utils.checkpoint import checkpoint

def heavy_function(x):
    """模拟计算密集的函数"""
    return x * 2

x = torch.randn(2, 3, requires_grad=True)

print("=== 不使用 checkpoint ===")
y1 = heavy_function(x)
y2 = heavy_function(y1)
y3 = heavy_function(y2)
loss1 = y3.sum()
# 前向时保存了 y1, y2, y3
print("保存了所有中间值")
print()

print("=== 使用 checkpoint ===")
y1_ckpt = checkpoint(heavy_function, x, use_reentrant=False)
y2_ckpt = checkpoint(heavy_function, y1_ckpt, use_reentrant=False)
y3_ckpt = checkpoint(heavy_function, y2_ckpt, use_reentrant=False)
loss2 = y3_ckpt.sum()
# 前向时不保存中间值，反向时重新计算
print("前向不保存，反向重算")
print("节省内存，增加计算")

Checkpointing 的权衡： - 优点：节省内存 - 缺点：反向时需要重新计算前向（增加计算量）

Mini 实现：最小的反向图执行器

下面实现一个最小反向图执行器：

# labs/L7/mini_autograd.py
from typing import List, Tuple, Optional
from dataclasses import dataclass
import numpy as np


@dataclass
class Tensor:
    """最小的 Tensor 类"""
    data: np.ndarray
    grad: Optional[np.ndarray] = None
    requires_grad: bool = False
    grad_fn: Optional['GradFn'] = None

    def backward(self):
        """执行反向传播"""
        if self.grad_fn is None:
            raise RuntimeError("No grad_fn (leaf tensor or no_grad context)")

        # 初始化梯度为 1（标量 loss）
        self.grad = np.ones_like(self.data)

        # 拓扑排序
        topo = []
        visited = set()

        def build_topo(fn):
            if fn is None or fn in visited:
                return
            visited.add(fn)
            for inp in fn.inputs:
                if inp.grad_fn is not None:
                    build_topo(inp.grad_fn)
            topo.append(fn)

        build_topo(self.grad_fn)

        # 反向执行
        for fn in reversed(topo):
            fn.backward()


class GradFn:
    """反向函数基类"""
    def __init__(self, *inputs: Tensor):
        self.inputs = inputs
        self.output = None

    def backward(self):
        """计算输入的梯度"""
        raise NotImplementedError


class AddBackward(GradFn):
    """加法的反向"""
    def backward(self):
        # ∂loss/∂a = ∂loss/∂out
        # ∂loss/∂b = ∂loss/∂out
        a, b = self.inputs
        if a.requires_grad:
            if a.grad is None:
                a.grad = self.output.grad.copy()
            else:
                a.grad += self.output.grad
        if b.requires_grad:
            if b.grad is None:
                b.grad = self.output.grad.copy()
            else:
                b.grad += self.output.grad


class MulBackward(GradFn):
    """乘法的反向"""
    def backward(self):
        # ∂loss/∂a = ∂loss/∂out * b
        # ∂loss/∂b = ∂loss/∂out * a
        a, b = self.inputs
        if a.requires_grad:
            grad = self.output.grad * b.data
            if a.grad is None:
                a.grad = grad
            else:
                a.grad += grad
        if b.requires_grad:
            grad = self.output.grad * a.data
            if b.grad is None:
                b.grad = grad
            else:
                b.grad += grad


class MatmulBackward(GradFn):
    """矩阵乘的反向"""
    def backward(self):
        # ∂loss/∂a = ∂loss/∂out @ b.T
        # ∂loss/∂b = a.T @ ∂loss/∂out
        a, b = self.inputs
        if a.requires_grad:
            grad = self.output.grad @ b.data.T
            if a.grad is None:
                a.grad = grad
            else:
                a.grad += grad
        if b.requires_grad:
            grad = a.data.T @ self.output.grad
            if b.grad is None:
                b.grad = grad
            else:
                b.grad += grad


# 算子实现
def add(a: Tensor, b: Tensor) -> Tensor:
    """加法"""
    result = Tensor(
        data=a.data + b.data,
        requires_grad=a.requires_grad or b.requires_grad
    )
    if result.requires_grad:
        result.grad_fn = AddBackward(a, b)
        result.grad_fn.output = result
    return result


def mul(a: Tensor, b: Tensor) -> Tensor:
    """乘法"""
    result = Tensor(
        data=a.data * b.data,
        requires_grad=a.requires_grad or b.requires_grad
    )
    if result.requires_grad:
        result.grad_fn = MulBackward(a, b)
        result.grad_fn.output = result
    return result


def matmul(a: Tensor, b: Tensor) -> Tensor:
    """矩阵乘"""
    result = Tensor(
        data=a.data @ b.data,
        requires_grad=a.requires_grad or b.requires_grad
    )
    if result.requires_grad:
        result.grad_fn = MatmulBackward(a, b)
        result.grad_fn.output = result
    return result


# 测试
if __name__ == "__main__":
    print("=" * 70)
    print("Mini Autograd 测试")
    print("=" * 70)
    print()

    # 场景 1: 简单加法
    print("场景 1: y = a + b")
    a = Tensor(np.array([1.0, 2.0]), requires_grad=True)
    b = Tensor(np.array([3.0, 4.0]), requires_grad=True)
    y = add(a, b)
    y.backward()
    print(f"a.grad: {a.grad}")  # 应该是 [1, 1]
    print(f"b.grad: {b.grad}")  # 应该是 [1, 1]
    print()

    # 场景 2: 乘法
    print("场景 2: y = a * b")
    a = Tensor(np.array([2.0, 3.0]), requires_grad=True)
    b = Tensor(np.array([4.0, 5.0]), requires_grad=True)
    y = mul(a, b)
    y.backward()
    print(f"a.grad: {a.grad}")  # 应该是 b.data = [4, 5]
    print(f"b.grad: {b.grad}")  # 应该是 a.data = [2, 3]
    print()

    # 场景 3: 矩阵乘
    print("场景 3: y = A @ B")
    A = Tensor(np.array([[1.0, 2.0], [3.0, 4.0]]), requires_grad=True)
    B = Tensor(np.array([[5.0], [6.0]]), requires_grad=True)
    y = matmul(A, B)
    y.backward()
    print(f"A.grad:\n{A.grad}")  # 应该是 [[5, 6], [5, 6]]
    print(f"B.grad:\n{B.grad}")  # 应该是 [[4], [6]]
    print()

    # 场景 4: 梯度累积（共享参数）
    print("场景 4: 梯度累积")
    x = Tensor(np.array([1.0, 2.0]), requires_grad=True)
    y1 = mul(x, Tensor(np.array([2.0, 2.0])))
    y2 = mul(x, Tensor(np.array([3.0, 3.0])))
    y = add(y1, y2)
    y.backward()
    print(f"x.grad: {x.grad}")  # 应该是 [2+3, 2+3] = [5, 5]
    print("梯度累积：x 被使用了 2 次，梯度相加")

常见陷阱

陷阱 1：忘记清零梯度

以下写法存在问题：

for epoch in range(10):
    for batch in dataloader:
        loss = model(batch)
        loss.backward()  # 忘记清零，梯度累积
        optimizer.step()

改为：

for epoch in range(10):
    for batch in dataloader:
        optimizer.zero_grad()  # 清零梯度
        loss = model(batch)
        loss.backward()
        optimizer.step()

陷阱 2：原地修改导致梯度错误

以下写法存在问题：

x = torch.tensor([1.0, 2.0], requires_grad=True)
y = x * 2
x.add_(1)  # 原地修改
loss = y.sum()
loss.backward()  # RuntimeError: modified by inplace operation

为什么错： - 反向传播需要用到前向的 x - 原地修改破坏了保存值

改为：

x = torch.tensor([1.0, 2.0], requires_grad=True)
y = x * 2
x = x + 1  # 非原地
loss = y.sum()
loss.backward()

陷阱 3：多次 backward 不 retain_graph

以下写法存在问题：

loss = model(x)
loss.backward()
loss.backward()  # RuntimeError: Trying to backward through the graph a second time

为什么错： - 第一次 backward() 后，反向图被释放（节省内存） - 第二次无法执行

改为：

loss = model(x)
loss.backward(retain_graph=True)  # 保留反向图
loss.backward()  # 现在可以

注意：retain_graph=True 会占用更多内存，只在必要时使用。

自测题

  1. 为什么反向图必须按拓扑序执行？
  2. 共享参数的梯度如何累积？举例说明。
  3. retain_graph=True 什么时候需要？代价是什么？

details 答案

  1. 拓扑序保证依赖正确 - 一个节点执行时，其所有后继（梯度的来源）已经计算完成 - 如果顺序错误，会使用未计算的梯度，导致结果错误 - 例如：loss = f(g(x)) 必须先计算 ∂loss/∂f，再计算 ∂loss/∂g

  2. 梯度累积示例 python W = torch.tensor([[1.0]], requires_grad=True) x = torch.tensor([[2.0]]) y1 = W @ x # 第一次使用 W y2 = W @ x # 第二次使用 W loss = (y1 + y2).sum() loss.backward() # W.grad = ∂loss/∂W (from y1) + ∂loss/∂W (from y2) # = 2 + 2 = 4

  3. retain_graph=True 的使用场景 - 需要多次 backward 同一个 loss（如 GAN 的判别器和生成器） - 计算高阶梯度（梯度的梯度） - 代价：保留所有中间节点和保存值，占用更多内存

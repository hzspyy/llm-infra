# 实验与证据规范

设计或运行实验、解释测量结果时读取。连接远程机器前另读 `ENVIRONMENTS.md`，以其中的机器目录、缓存和工具链记录为准。

## 证据与测量

- 区分源码事实、实测结果、公式预测和待验证解释。源码注明版本；实测注明硬件、输入、配置、命令及原始文件。
- 原始数字从工件逐字复制，不凭记忆转述。计算值给出公式、输入与单位，不伪装成原始读数。
- 带宽实验必须包含工作集大于目标 GPU L2 的尺寸；表格显式列出「在 L2 吗」。crater 的既有 L2 记录为 96 MiB，换机器时重新核对。
- 参数扫描覆盖拐点两侧。说明预热、同步、重复次数及统计口径，区分 profiler 测量与正常运行。
- 框架层模拟不能代表 kernel 内实现的代价；输出相同不能证明实现相同。跨机器数据不能直接用于解释另一台机器的运行时间。
- 预测与实测冲突时保留实测。未解释的趋势标注「这条趋势未解释，不要引用」，列出所需诊断。
- 保留负面和不确定结果。未实测内容标 `UNVERIFIED`，说明缺少的硬件、软件、容量或运行条件。
- `results/` 历史文件只读；新实验使用新文件名。修正文中的解释，不能修改原始结果迎合解释。

## 运行边界

- 可以使用 crater，其实验写入限定在 `/scratch/learn/`。其他机器使用 `ENVIRONMENTS.md` 中各自的项目学习目录；运行前核对缓存与工具链配置并加载对应 `env.sh`。
- 每次 GPU 实验前检查占用。独占 GPU 可按实验需要使用接近整卡的可用显存，不强制预留固定容量或限制使用比例；共享 GPU 按实际可用资源安排预算，不挤占其他任务。`safe_util()` 的旧默认值不是项目要求。
- worldvln 存储紧张，下载前检查余量，共用已有权重，不重复落盘。
- 不修改共享容器或安装系统包。工具用 deb 解包和 `LD_LIBRARY_PATH` 包装，禁止 `apt install`。
- ncu 实验使用 spark；其他机器的计数器权限限制见环境记录。nsys / torch.profiler 按实际可用性选用。
- Jetson 只用预编译 wheel，不在机器上编译。

[A] 消融：去掉 1/sqrt(d_head)
    注意力分数是 d_head 个乘积之和。若各分量独立、方差为 1，
    这个和的方差就是 d_head=8，标准差 sqrt(d_head)=2.828。
    softmax 对输入尺度敏感：分数越大，分布越尖。除以 sqrt(d_head) 把尺度拉回来。
    下面固定 64 个 key、扫 d_head，每格取 200 次随机试验的平均：

      d_head     缩放        分数标准差         平均最大概率        平均熵       softmax 梯度尺度
           8      是        0.957         0.0982     3.7165           0.962879
           8      否        2.769         0.4216     2.0496           0.715786
          64      是        0.981         0.1104     3.6858           0.959841
          64      否        8.032         0.7897     0.5868           0.292337
         256      是        0.997         0.1086     3.6799           0.960858
         256      否       15.811         0.9023     0.2534           0.140448

    不缩放时 d_head 越大，分数的标准差越大（≈ sqrt(d_head)），
    最大概率趋近 1、熵趋近 0——分布塌成 one-hot。
    最后一列是 softmax 雅可比对角元之和 Σp(1-p)：p 接近 0 或 1 时它趋于 0，
    也就是**梯度消失**。这是缩放的真正理由，不只是「数值好看」。
    参照：64 个 key 的均匀分布，熵 = ln(64) = 4.1589，Σp(1-p) = 0.9844

[B] 消融：去掉位置编码
    注意力算的是「查询与每个键的相似度」，它本身不知道谁在前谁在后。
    不加位置编码时，交换前面两个 token（保持最后一个不变），
    最后一个位置看到的键值**集合**完全没变，输出应当相同。
    要干净地验证这一点，必须满足两个条件：

      1. 同一组权重（不是两个随机初始化的模型），只切换 use_pos；
      2. 单层。多层时第 1 层在位置 0 和 1 上的输出本身就不同，
         第 2 层看到的集合已经变了，等式不再成立。

    A = '风吹过' ids=[16, 6, 14]    B = '吹风过' ids=[6, 16, 14]
      层数     位置编码        末位 logits 最大差
       1        无            1.043e-07
       1        有            5.605e-02
       2        无            4.412e-02
       2        有            6.380e-02

    单层无位置编码那一行接近机器精度：两次前向在数学上是同一个和，
    只是浮点加法的顺序不同（对照 L2.4 关于累加顺序的讨论）。
    加上位置编码后差值涨了约 5 个数量级——模型这才分得清「风吹」和「吹风」。
    两层时即使没有位置编码差值也不为零：第 1 层在位置 0 与 1 上
    分别看到 {风} 和 {风,吹}，A、B 两种输入下这两个集合不同。

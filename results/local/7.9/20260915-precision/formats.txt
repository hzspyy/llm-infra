A 四种低位宽格式
==============================================================================
格式                位宽         max        最小正规       最小次正规      1 附近间距       非零取值数
FP8 E4M3           8       448.0   1.562e-02   1.953e-03      0.1250         253
FP8 E5M2           8     57344.0   6.104e-05   1.526e-05      0.2500         247
FP4 E2M1           4         6.0   1.000e+00   5.000e-01      0.5000          15
E8M0(scale)        8       2^127      2^-127           -          ×2         255

E2M1 的全部非负取值：[0.0, 0.5, 1.0, 1.5, 2.0, 3.0, 4.0, 6.0]

饱和与归零（torch 2.14 的 eager 转换）：
  输入          ['500', '448', '447.9', '0.002', '0.001', '0.0002', '1e-05']
  → E4M3        ['448', '448', '448', '0.001953', '0.001953', '0', '0']
  500 被截到 448 而不是变成 Inf：E4M3 的 fn 变体没有 Inf 编码。
  2e-4 低于 E4M3 的最小次正规数 1.95e-3，直接归零。
  torchao 的 to_fp8_saturated 注明：PyTorch 2.11 及更早的 eager 转换不饱和，
  需要显式 clamp；2.12 起 eager 也饱和，这条差异按版本判断。

B 同一个张量，五种缩放粒度
==============================================================================
张量 (128, 256)，主体 ~N(0,1)，两个离群点 ±40/±32
方案                                    scale 个数    SQNR(dB)        最大相对误差
per-tensor E4M3                              1       31.85      1.00e+00
per-tensor E5M2                              1       25.72      1.11e-01
rowwise E4M3（沿最后一维）                        128       31.81      8.39e-01
MXFP8 block=32 E8M0 scale                 1024       30.84      8.39e-01
NVFP4 block=16 单级 scale                   2048       20.39      1.00e+00
NVFP4 block=16 两级 scale                   2048       20.39      1.00e+00

离群点决定 per-tensor 的 scale，其余元素被压进极少的几个量级——
块缩放把一个离群点的影响限制在它所在的块内。
这张表上 NVFP4 的单级与两级 scale 完全相同：所有块 scale 都落在 E4M3 的范围内。

两级 scale 在块之间量级差距很大时才起作用：
  块 amax 跨 8 个数量级时：单级 scale SQNR=3.23 dB，两级 scale SQNR=20.41 dB
  单级时块 scale 要直接存进 E4M3（最大 448、最小次正规 1.95e-3），超范围的块整体失真；
  两级把块 scale 先除以一个 per-tensor FP32 再存，等于把 E4M3 的窗口搬到合适的位置。

MX 的 scale 只取 2 的幂（FLOOR 模式），代价是每块最多浪费近 2 倍动态范围：
  第 0 块 amax=40.000000 → floor(log2)=5 → scale=2^-3
  缩放后该块最大值=320.00，E4M3 上限 448，利用率 71.4%
  换成 CEIL/RCEIL 模式可以提高利用率，代价是块内最大值可能需要饱和处理。

==============================================================================
C 转置：什么时候必须重新量化
==============================================================================
scale 取 2 的幂时（torchao rowwise 的默认）：
  沿最后一维 SQNR=33.47 dB，沿第 0 维 SQNR=33.47 dB
  两种分组下结果不同的元素占 0.00%，最大差=0.0000
  乘 2 的幂只改指数，E4M3 的舍入网格是相对的，多数元素不受分组影响；
  只有掉出窗口两端（饱和，或落进次正规与零）的元素会因为分组不同而改变。

换成非 2 的幂 scale（tensorwise recipe 的默认）：
  结果不同的元素占 99.1%，最大差=0.1981
  scale 不是 2 的幂时，缩放本身引入舍入，分组一变整张网格都变。

MX 的 32 元素块同样沿最后一维切分：
  先按行量化再转置 vs 直接对转置量化：最大差=0.2500，不同元素占 1.03%
  从高精度原张量量化 SQNR=32.26 dB；对已量化结果再量化 SQNR=32.70 dB

块沿归约维连续是 tensor core 的要求，前向与反向的归约维不同，
所以同一个张量需要两个方向的量化结果。Transformer Engine 的做法是
从同一份高精度输入直接产出正反两份，避免对量化结果再量化的二次损失。

==============================================================================
D 三类 GEMM：量化轴、累加精度与 fast_accum
==============================================================================
torchao rowwise recipe 的量化轴（Float8Linear 源码）：
  GEMM                        左操作数                      右操作数                      
  output = X·Wᵀ               input 沿 -1                weight 沿 0                
  grad_input = dY·W           grad_output 沿 -1          weight 沿 -1               
  grad_weight = dYᵀ·X         grad_output 沿 0           input 沿 0                 
  同一个 weight 在前向沿 0、在 grad_input 沿 -1，两次量化结果不同。

  GEMM                        SQNR(dB)       相对 Frobenius 误差
  output = X·Wᵀ                  28.61             3.711e-02
  grad_input = dY·W              28.60             3.716e-02
  grad_weight = dYᵀ·X            28.54             3.743e-02
  grad_weight 走 BF16             52.55             2.359e-03   ← rowwise_with_gw_hp
  这条配方把三个 GEMM 里最影响权重更新的一个留在高精度，其余两个仍是 FP8。

累加精度：把 K 维分成 32 元素一组依次累加，只改累加器 dtype
  输入量级        累加 dtype      SQNR(dB)        |输出|最大       非有限元素
  ×1          float32          28.61           4.5           0
  ×1          float16          28.61           4.5           0
  ×150        float32          28.53       99687.5           0
  ×150        float16          28.13       65504.0         456
  常规量级下量化噪声盖过累加噪声，两种累加器看不出差别；
  输入放大 150 倍后部分和越过 65504，FP16 累加器直接产生 Inf。
  低精度累加的风险在动态范围，不在有效位数。
  torchao 默认只给前向 GEMM 开 use_fast_accum，反向两个 GEMM 保持关闭：
  梯度的累加长度和数值范围都更不友好，省下的时间换不回精度。

==============================================================================
E 随机舍入：消除重复量化的系统偏差
==============================================================================
  待量化值 1.2，E2M1 的相邻可表示值 1.0 / 1.5
  最近邻舍入：全部得到 [1.0]，均值=1.000000，偏差=-0.200000
  随机舍入：取值 [1.0, 1.5]，均值=1.205933，偏差=+0.005933（期望为 0）

把同一个梯度量化后累加 200 次（模拟多步累积或多 rank 归约）：
  真值=240.0  最近邻=200.0（相对偏差 -16.67%）  随机舍入=242.0（+0.83%）
  偏差不随步数平均掉，它是确定性的方向误差；随机舍入把它换成方差。
  TE 的 NVFP4 配方只对梯度使用随机舍入，权重与激活仍用最近邻。

==============================================================================
F Hadamard 变换：换一个坐标系再量化
==============================================================================
  块内 最大/中位数 之比：变换前 9.6 → 变换后 3.2
  被量化成 0 的非零元素：直接 582/4096，经 Hadamard 141/4096
  张量 SQNR：直接 22.15 dB，经 Hadamard 18.81 dB
  GEMM 输出 SQNR：直接 18.43 dB，先变换再量化 16.86 dB

  元素分位                  平均相对误差(直接)        平均相对误差(Hadamard)
  最小 50%                     0.354                   1.575
  50–90%                     0.167                   0.142
  90–99%                     0.098                   0.073
  最大 1%                      0.022                   0.035

  变换把块内尖峰摊平，块 scale 不再被一个元素绑架，被压成零的元素少了约 4/5；
  代价是原本很小的元素接收到了从大元素摊过来的噪声，它们的相对误差反而变大，
  按能量计的 SQNR 因此略降。换句话说，选什么判据决定这个变换是赚是赔。
  正交性保证 (XH)(WH)ᵀ=XWᵀ，所以它是一次可以抵消的坐标变换，代价是两次小矩阵乘。
  TE 只在 weight 梯度这条路径上使用 16×16 随机 Hadamard；它的收益依据是
  NVFP4 预训练配方的端到端质量，本段合成张量的读数不能代替那个结论。

G scale 本身的开销
==============================================================================
格式                                  数据位/元素      scale 位/元素        合计     相对 BF16
BF16                                    16           0.000    16.000       1.000
FP8 per-tensor                           8           0.001     8.001       0.500
FP8 rowwise(K=256)                       8           0.125     8.125       0.508
MXFP8 block=32                           8           0.250     8.250       0.516
NVFP4 block=16 两级                        4           0.500     4.500       0.281

NVFP4 的块 scale 让每元素的实际位宽从 4 升到 4.5，另加一个 per-tensor FP32；
换算显存和带宽时按实际位宽算，不要按标称的 4 bit。
训练还要记另一份账：quantize kernel 的读写、转置副本、以及
delayed scaling 的 amax 历史（每个张量一段定长 buffer）都是额外状态。

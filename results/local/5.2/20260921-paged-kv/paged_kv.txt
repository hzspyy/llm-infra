值函数 v_p = f(v_(p-1), t_p) mod 2^61-1，与 token 前缀一一对应

[A] 单请求 + 重复请求：复用块的内容是否等于重算
  r0: tokens=2048 computed=2048 blocks=128
     idx  block  ref  valid  full  cached
       0      0    1     16  True    True
       1      1    1     16  True    True
       2      2    1     16  True    True
    ...（共 128 块，其余省略）
    r0 首次：复用 0 块 / 重算 2048 token；内容对拍 2048 位置，不一致 0
    r1 复用：复用 127 块 / 重算 16 token；内容对拍 2048 位置，不一致 0
    r2 关闭 num_tokens-1 上限（块池原始语义）：复用 128 块 / 重算 0 token；内容不一致 0

[C] fork 后分叉写入：COW 是否保护父序列
    块对齐：COW 复制 0 次；父序列内容不一致 0，子序列不一致 0（对拍 68/68 位置）
      父表尾：[(3, 2, 16), (4, 1, 4)]  子表尾：[(3, 2, 16), (5, 1, 4)]
    块内偏移：COW 复制 1 次；父序列内容不一致 0，子序列不一致 0（对拍 74/74 位置）
      父表尾：[(3, 2, 16), (4, 1, 10)]  子表尾：[(3, 2, 16), (5, 1, 10)]
    关闭 COW：别名写入 2 次；后写的父序列内容不一致 1 位置（首个位置 70），先写的子序列不一致 0 位置

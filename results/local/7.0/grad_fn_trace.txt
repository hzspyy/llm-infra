======================================================================
追踪 grad_fn 的创建
======================================================================

x = torch.randn(2, 3, requires_grad=True)
x.grad_fn: None
x.requires_grad: True
x.is_leaf: True

W = torch.randn(4, 3, requires_grad=True)
h = x @ W.t()
h.grad_fn: <MmBackward0 object at 0x1053b12a0>
h.grad_fn.next_functions: ((<AccumulateGrad object at 0x1053b12d0>, 0), (<TBackward0 object at 0x1053b1a80>, 0))
h.is_leaf: False

y = torch.relu(h)
y.grad_fn: <ReluBackward0 object at 0x1053b1a50>
y.grad_fn.next_functions: ((<MmBackward0 object at 0x1053b12a0>, 0),)

loss = y.sum()
loss.grad_fn: <SumBackward0 object at 0x1053b1b40>
loss.grad_fn.next_functions: ((<ReluBackward0 object at 0x1053b1a50>, 0),)

======================================================================
观察到什么
======================================================================
1. 叶子节点（x, W）没有 grad_fn
2. 每个算子创建一个 grad_fn（MmBackward、ReluBackward、SumBackward）
3. next_functions 指向前一个节点（反向图的边）
4. AccumulateGrad 是终点（把梯度写入 tensor.grad）

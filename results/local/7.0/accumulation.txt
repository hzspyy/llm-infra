======================================================================
梯度累积演示
======================================================================

场景 1: 参数被使用 1 次
----------------------------------------------------------------------
W1 @ x = tensor([[3.]])
loss = y1.sum() = 3.0
W1.grad: tensor([[1., 1.]])

场景 2: 参数被使用 2 次
----------------------------------------------------------------------
y2 = W2 @ x = tensor([[3.]])
y3 = W2 @ x = tensor([[3.]])
loss = (y2 + y3).sum() = 6.0
W2.grad: tensor([[2., 2.]])
梯度是场景 1 的 2 倍（因为 W2 被使用了 2 次）

场景 3: 多次 backward 不清空梯度
----------------------------------------------------------------------
第 1 次 backward 后 W3.grad: tensor([[1., 1.]])
第 2 次 backward 后 W3.grad: tensor([[2., 2.]])
第 3 次 backward 后 W3.grad: tensor([[3., 3.]])

场景 4: 清零后 backward
----------------------------------------------------------------------
第 1 次 backward 后 W4.grad（已清零）: tensor([[1., 1.]])
第 2 次 backward 后 W4.grad（已清零）: tensor([[1., 1.]])
第 3 次 backward 后 W4.grad（已清零）: tensor([[1., 1.]])

======================================================================
总结
======================================================================
1. PyTorch 默认累积梯度（不自动清零）
2. 训练循环需要手动 optimizer.zero_grad() 或 tensor.grad.zero_()
3. 共享参数的梯度会自动累加

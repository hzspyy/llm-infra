======================================================================
初始化 addmm dispatcher
======================================================================
  [注册] addmm.CPU → addmm_cpu
  [注册] addmm.CUDA → addmm_cuda
  [注册] addmm.AutogradCPU → addmm_autograd_cpu
  [注册] addmm.AutogradCUDA → addmm_autograd_cuda

======================================================================
场景 1: CPU, no grad
======================================================================

[调用] addmm
  dispatch keys: ['CPU']
  → 选中 CPU 实现: addmm_cpu
    [执行] CPU GEMM (调用 BLAS)

======================================================================
场景 2: CPU, with grad
======================================================================

[调用] addmm
  dispatch keys: ['AutogradCPU', 'CPU']
  → 选中 AutogradCPU 实现: addmm_autograd_cpu
    [Autograd] 记录前向信息
    [Redispatch] 到 CPU

[调用] addmm
  dispatch keys: ['CPU']
  → 选中 CPU 实现: addmm_cpu
    [执行] CPU GEMM (调用 BLAS)
    [Autograd] 注册反向函数

======================================================================
场景 3: CUDA, with grad
======================================================================

[调用] addmm
  dispatch keys: ['AutogradCUDA', 'CUDA']
  → 选中 AutogradCUDA 实现: addmm_autograd_cuda
    [Autograd] 记录前向信息
    [Redispatch] 到 CUDA

[调用] addmm
  dispatch keys: ['CUDA']
  → 选中 CUDA 实现: addmm_cuda
    [执行] CUDA GEMM (调用 cuBLAS)
    [Autograd] 注册反向函数

======================================================================
总结
======================================================================
这个 mini dispatcher 演示了:
  1. 如何根据 dispatch key 选择实现
  2. Autograd 包装如何 redispatch 到下一层
  3. 为什么同一个算子有多个实现

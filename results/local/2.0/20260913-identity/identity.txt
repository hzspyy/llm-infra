[A2] 对象相同 / 存储共享 / 数值相同：三个独立的问题
================================================================================================
比较对象                               同一对象    同一 storage   同 storage 指针   同 numel      展平后逐元素相等       形状相同  
--------------------------------------------------------------------------------------------------------------
x, x                                是          是              是           是            是            是    
x, x.reshape(6,4)                   否          是              是           是            是            否    
x, x.transpose(1, 2).reshape(-1)    否          否              否           是            否            否

x, x[0]                             否          是              是           否            —            否    

x.reshape(6,4) 与 x 不是同一对象，但共用 storage，ptr 相同 —— 它是 view。
x.transpose(1, 2).reshape(-1) 数值上等于 x 的转置展平，storage 完全不同 —— 它偷偷拷了一次。
数值相同可以由拷贝实现，也可以由 stride=0 实现，两者代价差一个量级。

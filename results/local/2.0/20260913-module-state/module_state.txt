================================================================================================
self._parameters : ['p']

[B3] to() 的遍历范围：谁被迁移，谁被漏掉
================================================================================================
to(torch.float64) 之后：
  lin.weight dtype : torch.float64   （对象 id 保持: True）
  p (Parameter)    : torch.float64
  run (buffer)     : torch.float64    （对象 id 保持: False）
  tmp (non-persist): torch.float64
  plain (普通属性)  : torch.float32    <- 没被迁移
  dtype 对照：之前 lin.weight=torch.float32 plain=torch.float32 p=torch.float32

--- 把同一个模型搬到 meta，普通属性留在原设备 -------------------------------------------------------------
  lin.weight.device : meta
  p.device          : meta
  run.device        : meta
  tmp.device        : meta
  plain.device      : cpu  dtype=torch.float32  <- 既没换设备也没换 dtype
  meta 模型的 state_dict 仍可枚举：['lin.bias', 'lin.weight', 'p', 'run']

--- 漏迁的普通属性会在前向里怎样暴露 --------------------------------------------------------------------
  float64 输入 + float32 plain -> torch.float64  （类型提升静默生效，不报错，但每一步都额外付转换成本）
  RuntimeError: Tensor on device cpu is not on the expected device meta!

[B5] mini_module 与 nn.Module 对拍
================================================================================================
比较项                              一致    mini / torch
------------------------------------------------------------------------------------------------
named_parameters 名字集合            是     ['lin.bias', 'lin.weight', 'p']
named_buffers 名字集合               是     ['run', 'tmp']
state_dict 键集合                   是     ['lin.bias', 'lin.weight', 'p', 'run']
共享参数去重后的名字                       是     ['emb.weight']
不去重时的名字                          是     ['emb.weight', 'head.weight']
共享参数 state_dict 双键               是     ['emb.weight', 'head.weight']

to(float64) 后的 dtype             一致    mini / torch
------------------------------------------------------------------------------------------------
lin.weight 被迁移                   是     torch.float64 / torch.float64
run 被迁移                          是     torch.float64 / torch.float64
tmp 被迁移                          是     torch.float64 / torch.float64
plain 不被迁移                       是     torch.float32 / torch.float32

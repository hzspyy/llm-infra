2. 反例：labels 已预移位，模型内部再移一次
====================================================================
单次 shift 的目标（样本 s0）: [9, 3, 7, 2, -100, -100]
两次 shift 的目标（样本 s0）: [3, 7, 2, -100, -100, -100]
N: 9 → 7；loss: 3.06575046 → 3.09727879
位置 0 的目标从第 2 个 token 变成第 3 个，整条序列错一位，loss 仍然是有限数。

3. prompt mask：attention 可见范围与监督范围是两个控制面
====================================================================
不屏蔽 prompt: N=11，loss=3.05892487
屏蔽 s2 的前 3 个 prompt 位置: N=9，loss=3.06575046

4. 反例：左 padding 不传 attention_mask
====================================================================
左 padding，有效位置 logits 最大差（传/不传 mask）: 2.510847e+00
与无 padding 的同一序列比较: 4.441e-16
右 padding 同一比较: 0.000e+00（因果 mask 已经挡住右侧 pad，所以缺 attention_mask 不改变有效位置）
loss mask 在两种情形下完全相同：它决定哪些预测计入目标，不决定谁能被看见。

====================================================================
5. 有效数为 0 的整步协议
====================================================================
N=0，Σloss=0.0；F.cross_entropy(reduction='mean') = nan
直接相除得到 nan，一次 backward 就会污染全部梯度；N==0 必须按整步协议跳过。

6. 连续目标对照：二维 flow matching 的分母单位
====================================================================
有效帧 9，有效坐标 18
按坐标平均 MSE = 1.90291256
按帧平均   MSE = 3.80582512（正好是前者的 2 倍）
同一 batch 的 token CE = 3.06575046 nats/token
CE 的单位是每个 target token 的负对数似然，MSE 的单位是每个坐标的平方误差；两者只共用「Σ 目标项 / 有效元素数」这套系统接口，数值本身不可排名。
改变分母约定（帧 vs 坐标）等价于把学习率乘上坐标数，梯度方向不变、步长变。

[B] 重建 vs 吸收：两条路径的对拍
==============================================================================
  推导：score = q_nope·k_nope + q_pe·k_pe，其中 k_nope = W_kb_nope · c
        => score = (q_nope W_kb_nopeᵀ)·c + q_pe·k_pe
  输出：o = Σ p_j v_j = (Σ p_j c_j) · W_kb_vᵀ，可再吸收进 o_proj
   float32: 吸收 vs 重建 max|err| = 1.080e-07（相对 1.08e-07）；再吸收 o_proj = 4.917e-07（相对 4.92e-07）
   float64: 吸收 vs 重建 max|err| = 2.498e-16（相对 2.50e-16）；再吸收 o_proj = 1.055e-15（相对 1.05e-15）

  两条路径在实数算术下等价；差别在**什么时候做哪个矩阵乘**：
  重建要为每个 KV 头物化 k_nope/v（[H, nope+v] 维），
  吸收则把 W_kb 的 K 部分挪到 Q 侧、V 部分挪到输出侧，缓存里只留 c。
  c 的维度 rank = 512，每 token 每层缓存 (rank+rope) 个元素。

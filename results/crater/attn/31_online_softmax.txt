[A] softmax 为什么必须减去最大值
==============================================================================
  softmax(x)_i = exp(x_i) / Σ_j exp(x_j)
  数学上，给每个 x 减去同一个常数 c，结果不变：
    exp(x_i - c) / Σ exp(x_j - c) = [exp(x_i)/exp(c)] / [Σ exp(x_j)/exp(c)]
  分子分母的 exp(c) 约掉了。所以减常数是**恒等变换**，不是近似。

--- 但在浮点里不减就会炸 --------------------------------------------------------------
  x 最大    10.0   exp(x) = [22026.46484375, 8103.083984375, 2980.9580078125]
                      朴素 softmax = [0.6652409434318542, 0.2447284758090973, 0.09003057330846786]
                      减最大值后   = [0.665241, 0.244728, 0.090031]
  x 最大    88.0   exp(x) = [1.6516362661361307e+38, 6.076030347399616e+37, 2.2352465286715966e+37]
                      朴素 softmax = [0.6652409434318542, 0.2447284609079361, 0.09003056585788727]
                      减最大值后   = [0.665241, 0.244728, 0.090031]
  x 最大   100.0   exp(x) = [inf, inf, inf]
                      朴素 softmax = [nan, nan, nan]
                      减最大值后   = [0.665241, 0.244728, 0.090031]
  x 最大  1000.0   exp(x) = [inf, inf, inf]
                      朴素 softmax = [nan, nan, nan]
                      减最大值后   = [0.665241, 0.244728, 0.090031]

  float32 能表示的最大值约 3.4e38，exp(88.7) 就到顶了。
  一旦 exp 溢出成 inf，inf/inf = nan，整行结果全毁。

--- 反方向：全是很小的负数 -------------------------------------------------------------
  exp(x) = [0.0, 0.0, 0.0]  -> 全部下溢成 0
  朴素 softmax = [nan, nan, nan]   (0/0)
  减最大值后   = [0.665241, 0.244728, 0.090031]

  减最大值之后，最大那一项恰好是 exp(0)=1，其余都在 (0,1]，
  既不会上溢也不会全部下溢。这就是所谓 safe softmax。

[B] 三遍 -> 两遍 -> 一遍
==============================================================================
  x = [4.623, -0.88, -6.536, 1.705, -3.254, -4.196, 1.21, 2.514]

--- 写法一：三遍扫描（教科书写法） ---------------------------------------------------------
  第1遍 m = max(x)      = 4.622988
  第2遍 p = exp(x - m)  = [1.0, 0.0041, 0.0, 0.0541, 0.0004, 0.0001, 0.0329, 0.1214]
  第3遍 l = Σp          = 1.212988
  y = p / l             = [0.8244, 0.0034, 0.0, 0.0446, 0.0003, 0.0001, 0.0272, 0.1001]
  代价：x 要从内存读 2 次（求 m 一次，求 p 一次）。

--- 写法二：一遍就把 m 和 l 都算出来（online） ---------------------------------------------
  关键恒等式：已经处理完前 k 个元素，手上有
      m_old = max(x_1..x_k)
      l_old = Σ_{i<=k} exp(x_i - m_old)
  来了第 k+1 个元素 x_new：
      m_new = max(m_old, x_new)
      l_new = l_old * exp(m_old - m_new) + exp(x_new - m_new)

  为什么那个 exp(m_old - m_new) 是对的：l_old 里每一项的基准是 m_old，
  现在基准要换成 m_new，每一项都要乘 exp(m_old)/exp(m_new)
  = exp(m_old - m_new)。整个和是线性的，所以提到外面乘一次就行。
  m_new >= m_old，所以这个因子 <= 1，永远不会放大 —— 数值上是安全的。

--- 按块做也一样（这才是 kernel 里的写法） -------------------------------------------------
  逐元素只是块大小为 1 的特例。块大小 B 时：
      m_blk = max(块内)          l_blk = Σ exp(块内 - m_blk)
      m_new = max(m_old, m_blk)
      l_new = l_old*exp(m_old-m_new) + l_blk*exp(m_blk-m_new)
  块大小 2:  m=4.622988  l=1.212988   与三遍写法一致: True
  块大小 4:  m=4.622988  l=1.212987   与三遍写法一致: True
  块大小 8:  m=4.622988  l=1.212988   与三遍写法一致: True

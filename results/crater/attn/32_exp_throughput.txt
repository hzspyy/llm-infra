对 attention 的账（每个打分元素 S[i,j]）：
  矩阵乘一侧：QK^T 贡献 2D FLOP，PV 贡献 2D FLOP，合计 4D
  softmax 一侧：1 次 exp（还有 max/加/乘若干，这里只算 exp）
  D= 32 : 矩阵乘 0.2505 clk, exp 0.0606 clk  -> exp 占 24.2%
  D= 64 : 矩阵乘 0.5010 clk, exp 0.0606 clk  -> exp 占 12.1%
  D=128 : 矩阵乘 1.0020 clk, exp 0.0606 clk  -> exp 占 6.1%
  D=256 : 矩阵乘 2.0039 clk, exp 0.0606 clk  -> exp 占 3.0%

D 越小，exp 占比越高。而且这个比值会随硬件代际**变差**：
tensor core 每代大幅加宽，SFU 基本不变。

[1] 去掉 i < n 判断后的越界写（每 SM 只有很少线程时量小，便于 sanitizer）
  [oob] guard=0  n=1025 grid=9  越界线程 = 127  不一致 = 0
  [oob] guard=1  n=1025 grid=9  越界线程 = 127  不一致 = 0

[2] 缺 __syncthreads 的跨 warp 读写（delay=1 只放大窗口，不改变对错）
  [race] sync=0 delay=0 block=128 grid=64  20 次里 0 次不一致，最多 0 个元素
  [race] sync=0 delay=1 block=128 grid=64  20 次里 0 次不一致，最多 0 个元素
  [race] sync=1 delay=1 block=128 grid=64  20 次里 0 次不一致，最多 0 个元素

[3] 发散的 shuffle 用错掩码
  [mask] correct=0  20 次里 20 次结果与掩码语义不符
  [mask] correct=1  20 次里 0 次结果与掩码语义不符

[3b] 发散的 __syncthreads
  [barrier] correct=0  同步返回=成功  写出值=63
  [barrier] correct=1  同步返回=成功  写出值=63

[4] 两条流之间缺事件依赖
  [stream] use_event=0  20 次里 3 次读到未完成的数据
  [stream] use_event=1  20 次里 0 次读到未完成的数据

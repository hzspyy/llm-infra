[A] 推导：softmax 的 Jacobian 与重算策略
==============================================================================
  设 P = softmax(S)，S = QKᵀ/√D。已知 dO（O = P V 的上游梯度）：
      dV = Pᵀ dO
      dP = dO Vᵀ
  softmax 的 Jacobian 作用在 dP 上：
      ds_j = p_j · (dp_j − Σ_i p_i dp_i)
  再回传到两个矩阵乘：
      dQ = (ds K) · scale        dK = (dsᵀ Q) · scale

  为什么必须有 p_j 这个因子：softmax 的每个输出都依赖整行，
  归一化项把 dP 的公共分量消掉了 —— 这一项就是把公共分量减掉。

  分块反向的关键：Σ_i p_i dp_i 看起来要把整行扫一遍，其实可以用正向输出换掉：
      Σ_i p_i (dO·V_i) = dO · (Σ_i p_i V_i) = dO · O
  于是每个 (q 块, k 块) 只需要 O 的一行，不用跨块归约。

  重算策略的边界（正向只存 Q/K/V、m/l、O，不存 P）：
      存的：Q/K/V（各 O(S·D)） + m/l（各 O(S)）
      不存的：P（O(S²)）
      代价：反向每个 (q 块, k 块) 重算一次 exp，正向的 exp 要做两遍
  和 7.0 的 activation checkpointing 是同一笔交易：用算力换显存。
  S 小时 P 装得下，重算反而多付一遍 exp；S 大时省下的是 O(S²)。

  5 维 softmax 的 Jacobian：手写 diag(p) − p pᵀ 与 autograd 的 max|err| = 0.000e+00
  同一 Jacobian 作用在随机 dp 上：两种写法 max|err| = 2.776e-17

  Σ_i p_i (dO·V_i) 与 dO·O：max|err| = 4.441e-16（-1.493262 vs -1.493262）

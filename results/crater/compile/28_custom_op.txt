--- 它出现在哪些 dispatch key 上 ---------------------------------------------------
  CUDA                         False
  CPU                          False
  Meta                         True
  Autograd                     True
  CompositeExplicitAutograd    True

  注意 CUDA 和 CPU 都是 False，而 CompositeExplicitAutograd 是 True：
  `torch.library.custom_op` 默认注册的是**与后端无关**的实现，
  由 CompositeExplicitAutograd 这个别名键覆盖所有后端（2.0 §3.3 那张表）。
  想按设备分别注册，用 `custom_op(..., device_types='cuda')` 或 `register_kernel`。

  Meta 和 Autograd 这两行虽然是 True，但注册的是**占位实现**：
  它们会在被调用时报错，提示你还没写 fake / autograd。
  这正是接下来两节要补的两件事。

=== NVIDIA GeForce RTX 5090 D   缓冲 256 MB

[1] 托管内存，CPU 先写过
    GPU 首次访问（含缺页迁移）    30.812 ms  ->     8.7 GB/s
    GPU 再次访问（页已在显存）     0.176 ms  ->  1525.2 GB/s
    缺页迁移让首次访问慢了 175.1 倍

[2] cudaMemPrefetchAsync 显式预取
    预取 256 MB     6.018 ms  ->    44.6 GB/s
    预取后 GPU 访问             0.191 ms  （已无缺页）

[3] 对照：cudaMalloc + pinned H2D
    显式 H2D 拷贝               5.882 ms  ->    45.6 GB/s
    之后 GPU 访问               0.199 ms  ->  1348.7 GB/s

结论：UVM 的价值是**编程方便与显存超额订阅**，不是速度。
      热路径上要可预测的性能，就用显式拷贝 + pinned 缓冲。

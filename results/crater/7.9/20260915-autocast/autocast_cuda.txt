torch 2.13.0+cu130 | device=cuda

==============================================================================
A autocast 在 cuda 上把哪些算子降到低精度（实测输出 dtype）
==============================================================================

 autocast dtype = bfloat16
   linear                           → bfloat16
   matmul                           → bfloat16
   bmm                              → bfloat16
   conv1d                           → bfloat16
   scaled_dot_product_attention     → bfloat16
   softmax                          → float32
   log_softmax                      → float32
   layer_norm                       → float32
   cross_entropy                    → float32
   sum                              → float32
   mean                             → float32
   exp                              → float32
   pow2                             → float32
   rsqrt                            → float32
   silu                             → float32
   add(fp32,fp32)                   → float32

 autocast dtype = float16
   linear                           → float16
   matmul                           → float16
   bmm                              → float16
   conv1d                           → float16
   scaled_dot_product_attention     → float16
   softmax                          → float32
   log_softmax                      → float32
   layer_norm                       → float32
   cross_entropy                    → float32
   sum                              → float32
   mean                             → float32
   exp                              → float32
   pow2                             → float32
   rsqrt                            → float32
   silu                             → float32
   add(fp32,fp32)                   → float32

低精度组是 GEMM 类算子；softmax / 归一化 / CE / 归约留在 FP32。
这张表按设备分别成立，CPU 与 CUDA 的策略表是两份实现，不能互相推断。
